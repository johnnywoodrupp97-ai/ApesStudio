# 16 — Glossary

| Term | Meaning |
|---|---|
| **Ada Okafor** | The Engineer's older sister; Directorate flight commander who leaves them on Pad 12 on Night Zero |
| **Anchor** | A hand-crafted location placed into the procedural universe (e.g., Tycho, Veyra-4's Garden Engine) |
| ***Anthesis*** | The Sower Seedship; final location of the campaign. (Botany: the flowering period of a plant.) |
| **Ark Directorate** | Military-corporate elite that fled to orbit on Night Zero; led by Director Halvard Crane |
| **Attraction** | A base's score (noise, light, power, gunfire, people) that sizes the hordes it draws |
| **Bloom / the Green** | Survivor slang for the Verdance and its visible growths |
| **Bloom Coverage** | 0–100% value per planet/system describing Verdance transformation; drives enemies, visuals, resources |
| **Bloom Heart** | Organic nest anchoring Hollow activity and Bloom spread |
| **Capability gate** | A limit with a reason in the world (vacuum, threat, range) and a way to beat it — never an invisible wall |
| **Choir, the** | Cult that deliberately lives in Stage 2 infection to "hear" the Verdance; led by Mother Sable |
| **Colony Overlay** | Management view for jobs, schedules, rooms, needs, relationships |
| **Contingency EDEN** | Crane's order, signed 48 hours before Night Zero, to fuel the arks and pack the Persephone cultures |
| **Council** | Periodic colony meeting where survivors propose policies |
| **Drift, the** | Pocket of ~60 procedural star systems linked by Sower jump lanes |
| **Engineer, the** | The player character (default name Ren Okafor) |
| **Event Director** | System that picks colony events based on state and pacing |
| **Free Haulers** | Independent spacer faction; traders; led by Captain Oye Adeyemi |
| **Garden Engine** | Sower terraforming machine (Veyra-4) |
| **Great Dying** | The end-Permian extinction, 252 million years ago; in-game, the Sowers' first harvest of Earth |
| **Green Moon** | Every third Earth night: a big horde wave aimed at your largest base |
| **Grid** | A connected structure of blocks (static structure, large grid, small grid) |
| **Hearth rule** | Pacing rule: every intense peak is followed by a return to the safe colony |
| **Hollow** | Any reanimated, Verdance-driven creature |
| **Horde Night** | Scheduled large Hollow attack (Earth) |
| **Kestrel Aerospace Complex** | Nevada spaceport where the game begins |
| **Kestrel Valley** | The 64 km² open region of Earth where Act I takes place |
| **KESTREL** | Facility AI companion that travels with the player |
| **Leads** | Journal entries (Story, Companion, Rumor, Signal) that replace a linear quest list |
| **Legacy** | The ending variant where the Engineer becomes the Weaver and the sandbox continues as adult Lily |
| **Loom** | Sower machine that can rewrite the Verdance's instructions; site of the final choice |
| **Memory Gardens** | The four preserved worlds inside the Seedship |
| **Moodlet** | Temporary mood modifier on a survivor |
| **Night Zero** | March 24, 2071 — the night of the outbreak |
| **Null carrier** | Rare human (1 in ~3,000) immune to the Verdance; Lily is one |
| **Peril meter** | Per-character danger during The Taking; driven by the defenses you built |
| **Persephone** | The 2059–2071 sample-return mission to Styx that brought the Verdance to Earth |
| **Point of no return** | The clearly marked start of Act IV; the galaxy stays open until you commit |
| **Project Eden** | Crane's plan to wipe and resettle Earth with a chosen population |
| **Pulse Drive** | In-system fast travel |
| **Resonance Crystal** | Sower-derived resource; jump fuel and precursor research |
| **Resonance Key** | Three Sower data artifacts needed to locate the Seedship |
| **Room Quality** | Score for a room's size, beauty, comfort, environment; drives survivor mood |
| ***Seraph*** | Ada's shuttle |
| **Sowers** | Ancient post-biological precursors who created the Verdance to terraform worlds |
| **Styx (2041 QX)** | Interstellar object — secretly a dormant Sower seed-pod |
| **Suppressant** | Early treatment that halts infection progression temporarily |
| **Tended mark** | The Sowers' "do not harvest" sequence carried by Null carriers; the Loom obeys only it |
| **Tessari** | Gentle six-limbed megafauna native to Veyra-4 |
| **Tortuga Drift** | Free Hauler ship-city inside a hollow asteroid |
| **TWR** | Thrust-to-weight ratio (must exceed 1 in local gravity to lift off) |
| **Verdance** | Canonical name of the pathogen: a designed biological terraforming agent. Lab name LZR-1 "Lazarus" |
| **Weaver** | The mind who stays inside the Loom to hold the new instruction at the end of the game |
| **Wrench** | The Engineer's nickname, given by Ada; used in all voice-over |
