# 14 — Expansion Roadmap

> The campaign ends; the universe doesn't. This roadmap shows how the game grows after launch and how each expansion plugs into existing systems.

## 14.1 Expansion principles
1. **Additive, not replacing.** New content = new definitions + new anchors + new quest graphs. Old saves keep working.
2. **Every expansion adds one to each pillar:** a build toy, a people feature, a new place, a story thread.
3. **The mystery keeps opening:** each expansion answers one Sower question and asks a bigger one.
4. **Free updates carry systems; paid expansions carry story and regions.**

## 14.3 Expansion concepts in detail

### "Return to Earth"
- **Premise:** Months after the ending, the colony returns to Earth for good.
- **CURE path:** a silent graveyard world; rebuild cities, rediscover pockets of survivors, contend with human warlords.
- **COMMUNE path:** a living green Earth; negotiate with the planetary mind; symbiotic architecture.
- **EXODUS/EDEN paths:** raid Earth for resources and survivors; Directorate remnants.
- **New systems:** city-scale building districts, road/rail logistics, large-scale farming, weather disasters.

### "The Gardeners"
- **Premise:** A Resonance Key from the Loom points beyond the Drift. The Sowers left a way-station — and one of them stayed behind.
- **New systems:** living hull blocks that grow and self-repair; Sower companions; genetic crop engineering.
- **Story question answered:** where the Sowers went. **New question:** what they were running from.

### "Other Gardens"
- **Premise:** Other intelligent species were "gardened" too — some survived.
- **New systems:** alien colonists with unique needs (e.g., a species that needs darkness, or one that communicates by color), inter-species relationships, diplomacy screen.

## 14.4 Evergreen content streams
- **Seasonal Drift Events:** limited-time anomalies (a rogue Seedship fragment, a Hauler festival, a Blood Bloom week).
- **Community Blueprint Challenges:** build prompts with in-game cosmetic rewards.
- **New Notable Survivors:** each update adds 3–5 hand-written survivors with personal quests.
- **Ship & block packs:** themed block sets (Directorate white-gold, Hauler industrial, Choir organic).

## 14.5 How new content plugs in (checklist for designers)

| To add… | You create… | Systems touched |
|---|---|---|
| A new block | Block definition + mesh + icon | Registry → build menu, research web, crafting |
| A new enemy | Enemy definition + model/anim + audio | Spawn rules, bestiary codex, Director |
| A new planet biome | Biome definition + material set + flora/fauna kits | Universe generator |
| A new trait | Trait definition + moodlets + barks | Colony sim, survivor generator |
| A new event | Event definition (conditions, choices, outcomes) | Event Director |
| A new story arc | Mission graph + dialogue + anchor level + flags | Quest system, galaxy map |
| A new faction | Faction definition + ships + outposts + reputation table | Territory sim, trade, dialogue |

## 14.6 Long-term narrative threads (seeded in the base game)
- **Walt Hennessey's pre-2071 log** mentions a 2050s probe that "went quiet near Styx" — hint of an earlier contact.
- **Sower glyph 64** (completing the glyph hunt) translates to: *"We are not the first gardeners."*
- **KESTREL's question** in the Loom (can an AI be a mind?) sets up an AI-rights storyline.
- **Lily's visions** of places she's never been — Null carriers may be receivers, not just immune.
- **The Styx beacon was answered** — but not only by the Seedship.
